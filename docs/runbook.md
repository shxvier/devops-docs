# Эксплуатация

1. Проверьте результат задания `pylint` в Pull Request. Оно запускает Pylint и MkDocs.
2. После слияния в `main` откройте Actions → Publish documentation.
3. Проверьте задания `build` и `deploy`, затем откройте URL среды `github-pages`.
4. Сверьте версию на главной странице и SHA в файле `build.txt` на сайте.

Для ручной публикации выберите Run workflow для ветки `main`. Если предыдущий
запуск завершился ошибкой, найдите первый шаг с ненулевым кодом и отправьте
исправление отдельным коммитом.
